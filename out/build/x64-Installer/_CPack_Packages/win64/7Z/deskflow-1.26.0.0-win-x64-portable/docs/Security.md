# Security Policy

## Supported Versions

The latest minor release is supported and receives security updates:
https://github.com/deskflow/deskflow/releases

## Reporting a Vulnerability

Please do not report suspected vulnerabilities in public issues.

Use one of these private channels first:

- GitHub Security Advisories (preferred): https://github.com/deskflow/deskflow/security/advisories/new
- Email: maintainers@deskflow.org

Please include:

- Affected Deskflow version and operating system
- Reproduction steps or proof-of-concept
- Expected impact and attack scenario
- Any relevant logs, traces, or screenshots
